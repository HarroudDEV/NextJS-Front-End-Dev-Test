# Contributing Guidelines

This repository is dedicated to evaluating Jets & Partners Front-End candidates. Follow the workflow below to keep assessments consistent and fair.

## For Candidates
1. **Fork** the repository and clone your fork.
2. **Create a branch** named `full-name/city-of-residency`.
3. **Implement the challenge** inside a new Next.js 14 project folder (e.g., `nextjs-app`).
4. **Commit frequently** with clear messages that describe what changed.
5. **Push** your branch to your fork and open a pull request to the `main` branch of this repo.
6. **Submit within 24 hours** of receiving the invitation email.

If you need to explain assumptions, add a short `NOTES.md` to your project directory or include clarifications in the pull request description.

## For Jets & Partners Reviewers
- Keep feedback inside the pull request thread to maintain a single source of truth.
- Label PRs with the candidate’s name and the page they cloned (e.g., `home-page`).
- Merge is not required; close the PR once the evaluation is complete.
- Do not expose proprietary assets or feedback publicly.

## Questions
Please reach out to your Jets & Partners recruiting contact instead of opening GitHub issues. This keeps the process private and organized.
