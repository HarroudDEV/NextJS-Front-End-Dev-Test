# NextJS Front-End Dev Test

This repository hosts the UI challenge for recruiting a Front-End (Next.js + UI/UX) engineer at Jets & Partners. Candidates clone one marketing page from the Jets & Partners website using a fresh Next.js 14 project and submit their work through a fork + pull request workflow.

## Quick Start
- Read `Task.md` for the full brief, acceptance criteria, and branch naming rules.
- Review `CONTRIBUTING.md` to understand how we expect the fork/branch/PR flow to work.
- Submit within 24 hours of receiving the invitation email.
- Keep the work proprietary—see `LICENSE.md` for details on usage and confidentiality.

## Repository Files
- `Task.md` – detailed instructions for the challenge.
- `CONTRIBUTING.md` – workflow guidance for candidates and maintainers.
- `LICENSE.md` – proprietary license limited to Jets & Partners’ recruiting process.

Please do not raise issues in this repository; direct all questions to your Jets & Partners recruiting contact.
